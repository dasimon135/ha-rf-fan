# Forum posts

Source text for posts this project maintains on forums, where the published copy
cannot be reviewed or diffed. Discourse keeps an edit history, but it is not
something you can read in a pull request, so the version that gets edited and
re-read lives here and the forum holds the published copy.

**Replies do not belong here.** A reply's canonical home is the thread that
contains it, together with what it was answering; a copy kept in the repository
would drift from it in silence. `.gitignore` keeps them out.
